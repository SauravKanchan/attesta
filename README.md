# trading-marketplace

A TEE-powered marketplace for verifiable automated trading strategies. Creators upload
TypeScript trading strategies that run inside a Trusted Execution Environment; investors
allocate USDC based on cryptographically verifiable performance.

Built on three layers: **Chainlink CRE Confidential Workflows** (compute), **Circle
Agent Wallets on Arc** (settlement), and **Privy** (investor onboarding).

- [docs/project-overview.md](docs/project-overview.md) — what the platform is, the actors,
  the architecture, and the verifiability model.
- [docs/prizes.md](docs/prizes.md) — the three partner technologies, what we build with
  each, and the constraints each imposes.
